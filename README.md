# Arrows

A single-player puzzle game for iPhone. The board is filled with arrow-shaped paths, and the
player clears it by tapping arrows whose way out is free. Every level, daily challenge and event
board is generated on the device from a seed, so the supply of puzzles is infinite and the same
puzzle is the same on every phone.

Status: project just started. The engine (generator, solver, difficulty rating) comes first, then
the app.
